## IT Helpdesk & Incident Resolution Bot


## Domain

Enterprise IT / ITSM / DevOps

## Corpus Objective

Build a domain-specific corpus containing more than 300 pages
of relevant English-language IT documentation.

## Target Corpus Size

Approximately 400–500 pages before cleaning.

## Planned Source Families

1. Ubuntu Server
2. Red Hat Enterprise Linux
3. Microsoft Intune / Endpoint Management
4. ServiceNow IT Operations Management
5. ITIL

## Selection Principles

- Prefer official documentation.
- Prefer technically detailed documentation over marketing material.
- Cover multiple IT helpdesk-relevant topics.
- Maintain source metadata.
- Record page counts before preprocessing.
- Retain only English-language documents.
- Track documents removed during cleaning.

## Planned Topic Coverage

- Linux system administration
- Linux storage and networking
- Linux services and troubleshooting
- Windows endpoint management
- Device enrollment
- Configuration and compliance
- IT operations
- Incident management
- Service management concepts
